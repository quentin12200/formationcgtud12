# Formation CGT - Application de Formation Syndicale

## 📝 Description
Application HTML autonome conçue pour animer une journée de formation syndicale CGT sur le fonctionnement statutaire d'un syndicat. Cette application fonctionne 100% en local, sans besoin de connexion internet (après le premier chargement des polices).

## 🚀 Fonctionnalités
- **Navigation fluide** entre les séquences pédagogiques
- **Table des matières** accessible à tout moment
- **Calcul automatique** des heures de fin de séquence
- **Impression/Export PDF** des séquences
- **Responsive design** (fonctionne sur mobile et tablette)
- **Structure modulaire** (HTML/CSS/JS séparés)

## 💻 Utilisation
1. Ouvrez le fichier `index.html` dans n'importe quel navigateur moderne
2. Naviguez entre les séquences avec les boutons "Précédent" et "Suivant"
3. Accédez au sommaire à tout moment via le bouton central
4. Pour imprimer ou exporter une séquence en PDF, utilisez le bouton "Imprimer" sur chaque slide

## 🔧 Structure des fichiers
- `index.html` - Structure principale de l'application
- `css/styles.css` - Styles et mise en page
- `js/script.js` - Fonctionnalités interactives
- `img/` - Dossier contenant les images (logo CGT)

## 🎨 Personnalisation
Pour personnaliser cette formation :
- Modifiez le contenu des slides dans `index.html`
- Ajustez les styles dans `css/styles.css`
- Les couleurs principales sont définies en variables CSS (--cgt-red, etc.)

## 📱 Compatibilité
- Fonctionne sur tous les navigateurs modernes
- Adapté aux écrans de toutes tailles (PC, tablette, smartphone)
- Optimisé pour l'impression et l'export PDF
